# Power BI Customization Guide

The included `.pbix` is the source dashboard used as the starting point. Power BI Desktop is required to edit it.

## Make the dashboard your own
1. Open the PBIX in Power BI Desktop.
2. Rename the report title to **Retail Sales & Customer Intelligence Analytics**.
3. Add KPI cards for Sales, Profit, Profit Margin, Orders, and Customers.
4. Add/refresh the RFM output from `data/cleaned/customer_rfm_segments.csv`.
5. Add a customer segment visual and an at-risk customer table.
6. Add a discount-band vs profit-margin visual.
7. Add slicers for Year, Region, Category, Segment, and Customer Segment.
8. Save as a new file, e.g. `Retail_Sales_Customer_Intelligence.pbix`.

Do not claim that the PBIX was completely created from scratch; it is the starting dashboard and should be substantially edited before public portfolio use.
