# Learning Guide

## Goal
Build enough understanding to explain the project honestly in a Data Analyst interview.

## Learn in this order
1. Python/Pandas: loading data, selecting columns, filtering, `groupby`, `agg`, `merge`, dates.
2. Data cleaning: missing values, duplicates, data types, derived columns, validation.
3. SQL: SELECT, WHERE, GROUP BY, HAVING, ORDER BY, JOIN, CTEs, window functions.
4. Power BI: data import, relationships, measures, slicers, KPI cards, charts, drill-through.
5. Business analytics: revenue, profit, margin, customer value, discount impact, regional performance.

## Interview checklist
Be able to explain the dataset, business problem, cleaning steps, three SQL queries, three dashboard KPIs, RFM segmentation, discount analysis, and at least five business insights.
